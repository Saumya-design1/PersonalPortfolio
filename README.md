## 📌 Features

- **📱 Fully Responsive:** Clean mobile-first interface optimized across phone, tablet, and desktop viewports[cite: 1, 2].
- **🎨 Modern UI/UX:** Styled with custom CSS properties, soft lavender accents, modern typography (`Plus Jakarta Sans`), and subtle hover micro-interactions[cite: 1, 2].
- **⚡ Fast Performance:** Pure HTML5 and CSS3 execution with zero dynamic JS frame overhead for ultra-fast render times[cite: 1, 2].
- **🎯 Dynamic Content Sections:**
  - **Hero Banner:** Eye-catching bio header with key profile tags.
  - **About Me:** Overview of B.Tech CS (AI & ML) background at KIET.
  - **Skills Grid:** Interactive showcase of programming languages and developer tools.
  - **Projects & Achievements:** Highlight cards for SIH Internal Hackathon, Hardware/Robotics, and Web concepts.
  - **Contact Card:** Direct links to GitHub, LinkedIn, and email.
